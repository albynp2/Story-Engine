Belum punya voice over? Pakai Edge TTS (gratis)

1) Install sekali: pip install edge-tts
2) Copy naskah di atas, simpan sebagai naskah.txt
3) Pilih suara, buat perintah, jalankan di terminal/CMD di folder yang sama
4) Upload voiceover.mp3 di atas dan voiceover.srt di bawah

Atau manual lewat terminal:

Per adegan (disarankan): buat script yang menghasilkan adegan1.mp3, adegan2.mp3, dan seterusnya. Simpan sebagai suara.py (format UTF-8), jalankan python suara.py, lalu upload semua file mp3-nya di atas.
