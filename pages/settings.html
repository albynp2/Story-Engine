Karakter Drama AI (referensi wajah)

Disarankan: buat karakter fiktif dulu (character sheet) di Flow/Gemini, lalu upload di sini. Deskripsi tampilan akan disalin kata demi kata ke tiap prompt, dan gambar dikirim ke Flow sebagai referensi jika ekstensi mendukung. Jangan pakai foto orang lain tanpa izin.

Ekstensi Google Flow

  1. Chrome: buka chrome://extensions, aktifkan Developer mode, klik Load unpacked, pilih folder flow-extension di project ini.
  2. Firefox: buka about:debugging → This Firefox → Load Temporary Add-on → pilih file manifest.json di folder flow-extension-firefox (izinkan akses situs di about:addons → ekstensi → Permissions).
  3. Login ke Google Flow di browser itu dan biarkan tab-nya terbuka.
  4. Status "Ekstensi Flow" di sidebar akan hijau. Lalu klik Generate otomatis di menu Explainer / Drama AI / Stickman.

Selector tombol Flow bisa berubah kapan saja. Kalau macet, ubah flow-extension/selectors.js.
